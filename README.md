# nltsa  

- Some R code to accompany [Nonlinear Time Series by Douc, Moulines, and Stoffer]([http://www.stat.pitt.edu/stoffer/nltsa](https://www.routledge.com/Nonlinear-Time-Series-Theory-Methods-and-Applications-with-R-Examples/Douc-Moulines-Stoffer/p/book/9781466502253)/)

- Note: there is not really a package for the text, but a quick and dirty method to get everything that is here is to treat it like a package using the following two lines:
  
```r
install.packages("remotes")   # if you don't have the package already
remotes::install_github("nickpoison/astsa/nltsa")
```
